Introduce tu token de acceso de GitHub

¿Cómo obtener el token?
Ve a github.com/settings/tokens → Generate new token → dale acceso al repositorio allstore → Permisos: Contents: Read and write. Copia el token y pégalo aquí.

❓ Cómo usar el panel

Guía rápida

📝 Editar un producto

Ve a Productos, busca el que quieras y toca el lápiz ✏️.

💵 Elegir moneda del precio

Puedes elegir entre USD o CUP. La tienda convierte automáticamente al otro valor.

🖼️ Subir imágenes

Si tienes mala conexión, sube una imagen a la vez y guarda. Luego edita el producto y añade la siguiente. Así se evitan errores.

⚠️ Importante

Los cambios tardan 30-60 segundos en reflejarse en la tienda pública.
