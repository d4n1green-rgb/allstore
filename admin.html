Introduce tu token de acceso de GitHub

¿Cómo obtener el token?
Ve a github.com/settings/tokens → Generate new token → dale acceso al repositorio allstore → Permisos: Contents: Read and write. Copia el token y pégalo aquí.

🖼️ Subir imágenes: dos métodos

Método 1 (automático): Selecciona la imagen y guarda. El panel la comprime a 600px y la sube. Puede fallar si la conexión está inestable.

Método 2 (manual, 100% fiable): Dentro del modal hay un botón azul "📤 Abrir GitHub para subir". Se abre una pestaña nueva del repositorio. Sube la imagen ahí y escribe el nombre del archivo en el campo del admin.

📝 Editar un producto

💵 Elegir moneda del precio

🗑️ Eliminar productos
